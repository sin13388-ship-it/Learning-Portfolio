CSS 層疊（Cascade）
瀏覽器在決定哪一個 CSS 樣式該套用時，會遵循一條被稱為 CSS 層疊（Cascade） 的核心規則。它會依序根據以下三個指標來打分數，分數高的贏:
  • 1,000 分：Inline style
  • 100 分：ID 選擇器（如 #my-id）
  • 10 分：Class 類別選擇器、屬性選擇器、偽類（如 .my-class, [type="text"], :hover）
  • 1 分：Element 元素選擇器、偽元素（如 body, p, div, ::before）

    • inline style setting 用單引號 ' Arial '
